# The Long Dark — Interactive Crafting Reference

An unofficial **Survivor Incognito Workshop** tool for *The Long Dark*. Search crafting recipes, check requirements, and organise the materials needed for your next survival project.

## Features

- **Instant recipe search** — find items by name, ingredients, and unlock requirements.
- **Crafting location filters** — narrow results by workbench, forge, ammunition equipment, cooking, and other crafting locations.
- **Base-game and DLC filters** — distinguish standard Survival Mode content from recipes requiring *Tales from the Far Territory*.
- **Detailed recipe cards** — view ingredients, quantities, tools, cooking requirements, and unlock conditions where applicable.
- **Material checklist** — add several recipes and see the combined quantities needed.
- **Accurate measurement units** — tracks items, kilograms, and litres rather than treating fractional amounts as whole items.
- **Saved progress** — the crafting list is stored locally in your browser; no account is needed.
- **Mobile-friendly layout** — designed for use alongside the game on phones, tablets, and computers.

## Recipe coverage

The current reference contains **139 entries** across **10 crafting locations**, including:

- Survival equipment, tools, and clothing
- Workbench and forge crafting
- Ammunition-related crafting
- Cooking and special recipes
- Base furnishings and Safehouse Customization items
- Recipes and equipment associated with *Tales from the Far Territory*

Some recipes require a recipe card, a particular cooking skill, special equipment, or paid DLC. The reference indicates these requirements where known.

## How to use

1. Open the crafting reference in your browser.
2. Search for the item you want to make, or select a crafting-location filter.
3. Check its ingredients and requirements.
4. Add the recipe to your crafting list, then adjust how many you want to make.
5. Use the combined material checklist to track what you still need.

Your list is saved on the device and browser you use. Clearing browser data or using a different browser may reset it.

## Cooking times and recipe accuracy

Cooking times can vary with **Cooking skill**. Where relevant, the reference distinguishes baseline cooking time from skill-adjusted time. The recipe dataset has been checked against published sources, and known discrepancies have been documented and corrected, but it is **not a guarantee of direct in-game verification for every entry**. Recipes and game systems may change in future updates.

This is a curated Survival Mode reference, not an exhaustive catalogue of every possible repair or food preparation action.

## Hosting on GitHub Pages

This project is a standalone HTML tool and does not require a server or database.

1. Upload **`index.html`** and **`README.md`** from this ZIP to your GitHub repository's main folder.
2. In **Settings → Pages**, choose **Deploy from a branch**, select **`main`**, and use **`/(root)`**.
3. Save and open the GitHub Pages address to test the tool.
4. If desired, configure a custom domain in GitHub Pages and your domain's DNS settings.

For a basic deployment, the only required site file is `index.html`. Keep the editable data and verification notes in the source kit for future updates.
